Scene Note: Neconyan documentation starter

Copy this scene-note folder into your test account's extensions folder, then
reload Neconyan. Open Extensions and find Scene Note's settings. It stores one
account-wide note under the neconyan_scene_note extension settings key. It does
not call a model or alter chats. Saving is scheduled through the app's settings
writer; the sample does not claim a confirmed server save.

Guide: https://platberlitz.github.io/neconyan-docs/extensions/first-extension/
