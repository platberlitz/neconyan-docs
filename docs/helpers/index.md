# Choose a helper

Choose a tool based on the writing task you want help with. Each has its own settings and may make additional model requests.

| You want to… | Use | What to know first |
| --- | --- | --- |
| Keep an outline or reference library | [Notebooks](notebooks.md) | Writing notes doesn't require a model connection |
| Ask for ideas without adding planning to the story | [Scratchpad](scratchpad.md) | You choose its context and connection |
| Run a repeatable helper around replies | [Agents and Companions](agents.md) | Some add instructions; others make extra requests |
| Recall events from a long Roleplay history | [Mewmory](mewmory.md) | Retrieval and extraction have separate settings |
| Find a specific utility | [Included tools](tools.md) | Each tool has its own scope and costs |

## Check what a helper can read

Before enabling a helper, check its context preview and learn when it runs. For example, saving a notebook note doesn't grant an assistant access to it; you choose what to share. Use the helper's activity view, where available, to see what ran and whether it changed anything.

## Begin with one useful task

For a writing session, a good first setup is a notebook for your outline and Scratchpad for questions about the current scene. Add an Agent for a recurring task. Add Mewmory when the saved history becomes difficult to keep in context.
