# About these docs

This is the official Neconyan handbook, built with [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/). It covers getting started, everyday writing, helpers and extension development.

## Version and scope

I've reviewed these guides against the **Neconyan 1.5.4 staging candidate at 999b46b3** on **10 November 2026**. This candidate is **not yet published**; [1.5.3 is the latest published release](https://github.com/platberlitz/Neconyan/releases/tag/v1.5.3). This edition adds Device sync guidance, the phone section buttons in Prompting Lab and World Info Lab, and the contained JannyAI browser. Some controls described here won't appear in 1.5.3.

The macro catalogue retains its reviewed 7 October snapshot. The Scene Note starter and extension styling guide now carry the accent button guidance; the other extension examples are unchanged from their reviewed 7 October snapshots. The macro guides explain which replies are still built on the server and which macros those refuse. The newer Agent-only placeholders are documented separately and don't change the registered macro count.

The practical guides focus on common tasks and link to longer references when you need the details. Those references may change after this edition. Model features still depend on your provider and model supporting them.

## Screenshots and artwork

All twenty-four workspace screenshots were captured from the 1.5.4 candidate on 10 November, using demonstration content and the bundled assistants, not private chats. The Proofreader example uses a fixed sample response through the real edit-history workflow; it isn't a live model conversation.

Miso, Taro and Nori use Neconyan's existing assistant artwork, with male, female and neutral variants. Their handbook dialogue is authored guidance, not a live model conversation. Gender preferences stay in the browser when storage is available.

## Improve a guide

Report an incorrect label or workflow with the page address, your app version and what you see instead. For screenshots, use demonstration data and keep credentials out of view. Useful additions explain a task someone can actually complete, including how to recognise a successful result.

The handbook is edited as Markdown. See the documentation repository's README for local preview and publishing instructions. Search runs in the browser over the built documentation; reading these pages doesn't require a Neconyan login or a model connection.
