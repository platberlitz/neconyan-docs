# Your first chat

Once [your model is connected](connections.md), open **Choose a character** on Home or **Characters** in the workspace sidebar. The bundled Miso, Taro and Nori cards give you somewhere to start before importing your own cast.

## Start a saved conversation

1. Choose a character and open their chat.
2. Use **Roleplay** for a normal character-chat transcript. You can explore the other modes later.
3. Read the character's opening message, then type your reply in the composer at the bottom.
4. Press Send and wait for the response. Some connections display it as it arrives; others return the completed reply.

On a desktop, keyboard sending follows your preferences. ++shift+enter++ lets you add a line break in the usual composer. On a phone, use the visible Send control.

!!! nori "Nori"
    Give the scene something to react to. An unexpected visitor will do nicely; we can discuss the weather once they've explained themselves.

## Change a reply

If the model's reply is close but has one wrong detail, use the message's edit action. If you'd like a different attempt, use the regeneration or swipe controls. A swipe is an alternative version of that reply; it doesn't create a second character.

The chosen version becomes the one your conversation continues from. Once later messages rely on a detail, changing an earlier reply can make the story inconsistent. Branch or start another chat when you want to explore a substantially different direction.

## Know what is being saved

Saved chats belong to the server you're using. Visit the same server and account to find them again. A different installation has a different library unless you've moved the data yourself.

**Start a temporary chat** on Home is deliberately temporary. Its messages aren't saved. If you're experimenting with something worth keeping, use a normal saved chat or export your work before you close it.

Most server-backed replies can keep running if you close the tab. That doesn't mean the computer, Android app or model service can be shut down safely in the middle of a request. Browser-only providers also depend on the browser staying active.

## If the reply feels wrong

- Check the selected character and [persona](../workspace/characters.md). The persona describes you in the conversation.
- Read the character's description and opening scenario. Contradictory instructions produce contradictory replies.
- Use a clear correction when a detail matters. Regenerating without addressing the cause can keep producing that mistake.
- Check the model and any enabled Agents before blaming the character card.

Once the basics work, you can add a [lorebook](../workspace/lorebooks.md), organise ideas in [Notebooks](../helpers/notebooks.md) or ask [Scratchpad](../helpers/scratchpad.md) about the scene without adding that discussion to the story.

For a screenshot tour of the chat controls, continue to [Roleplay](../workspace/roleplay.md).
