# Your first paws

Neconyan gives your characters somewhere to live and your chats somewhere to be saved. The replies come from a model you connect. Before you start, decide where the app will run and where those replies will come from.

## 1. Choose where to run it

| Your device | Start here | What stays running |
| --- | --- | --- |
| Windows, macOS or Linux | [Install on a computer](computer.md) | The Neconyan launcher on that computer |
| Android 11 or later | [Install the Android app](android.md) | The app's built-in server |
| iPhone or iPad | [Open it on your phone](phone.md) | Neconyan on a separate computer or server |
| A phone visiting an existing setup | [Connect over your home network](phone.md) | The computer that already has your data |

The server is the part that saves your chats and sends requests to your model. It can be running on the same device as the screen you're using, or somewhere else. Closing a browser tab and stopping the server are different things.

## 2. Connect a model

You can use an online provider with an API key, which is the credential that lets Neconyan request replies on your account, or a local model service you've already started. Neconyan doesn't download a language model for you.

Open **Connections** in the workspace sidebar and follow [Connect a model](connections.md). Start with one connection and keep the provider's recommended settings while you check it works.

!!! taro "Taro"
    A subscription to a provider's chat website doesn't automatically include API access. Check what your account actually includes before debugging a key that doesn't exist.

## 3. Open a character and send a message

Use **Choose a character** on Home, pick one of the bundled assistants and open a saved chat. Send something simple, such as asking Miso for a scene idea. Once you receive a reply, follow [Your first chat](first-chat.md) to learn swipes, editing and chat history.

If you choose **Start a temporary chat**, its messages aren't saved. Use it for a quick test, not a story you intend to keep.

## What can wait?

Agents, Mewmory, advanced sampling, custom formatting and extra extensions are optional. Add them when you have a reason to use them. If your basic connection isn't working yet, more helpers will only make the error harder to locate.

Already have a character collection? [Bring your old data](imports.md) after making a backup. If you just want to see what Neconyan can do, take the [workspace tour](../workspace/index.md).
