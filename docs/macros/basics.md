# Spacing and choices

These core macros handle spacing, comments, conditions and random choices.

For a choice that should stay fixed, use `pick` or the [saved-choice macros](saved-values.md). A fresh `random` or `roll` can change whenever the prompt is processed, including a preview or a repeated preparation step.
