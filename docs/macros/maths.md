# Maths

These Macro Enhanced macros calculate numbers before the prompt reaches the model. Use a decimal point and omit thousands separators from individual numbers.

**Not for Roleplay prompts.** These macros only run in the browser. If a Roleplay prompt uses one, the reply stops before the model request. Test them in the Macro Enhanced Playground, and read [Macro Enhanced in Roleplay prompts](index.md#macro-enhanced-in-roleplay-prompts) before putting them in a card, preset or lorebook entry.

`calc` handles an expression. The smaller helpers suit a single operation, such as keeping a value between 0 and 100. List helpers accept comma-separated values by default.
