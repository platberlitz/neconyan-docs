# Messages and chat settings

These core macros read the chat context supplied to the current operation. The usual source is Roleplay; they do not search every Conversation branch or Scratchpad session.

Message numbers start at **0**. Swipe numbers start at **1**. A swipe is an alternative reply for the same message.

Token limits describe the configured allowance. They do not prove that the provider accepts that amount, or tell you how many tokens the current prompt already uses.
