# Included-tool macros

These macros are registered by Dialogue Colors and Character Expressions. Their output depends on the selected character and those tools’ settings.

For setup, see [Included tools](../helpers/tools.md). Other extensions can register more names; check the extension’s own documentation and the installed macro reference.
