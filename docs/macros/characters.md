# Names and character cards

These core macros read the active persona, character card or group. Empty card fields usually produce empty text. They read what is saved; they do not invent missing character details.

In a solo chat, the character and persona are straightforward. In a group, the current speaker and group settings affect the result. Check the actual prompt if a group member’s name looks wrong.
